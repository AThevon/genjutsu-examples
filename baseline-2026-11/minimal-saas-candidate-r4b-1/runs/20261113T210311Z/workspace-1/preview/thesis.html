Ploverdesk: theses (proposal, not the build)

This page is the proposal for the two theses. It is throwaway and is not ported into the build. Headless run: UNVALIDATED.

Visual thesis

Visual thesis: a white, cool-neutral page set like an auditor's tick-and-tie sheet: near-black ink, hairline rules, and one colour only, a burnt-orange signal that marks a line that does not match; the action is solid ink. Type is the system sans with tabular figures, weights 400 and 600, on a tight scale. Airy on an 8px base, one left edge on a 72rem container, square 2px corners, flat, no shadows.

First screen: headline and actions at reading measure; below them, at container width, an example match sheet, one supplier invoice against its purchase order and delivery note, with no figures, only the brief's words. On a narrow frame each row stacks, every value beside its document name.

Allowed patterns: hairline rules on the rows of the match sheet and the spec list; the example match sheet, labelled "Example"; the tabular layout of the specs.

Set aside: SaaS hero with feature cards and logo strip; one centred sentence; ledger grid; Swiss minimal type. Kept: the auditor's tick-and-tie sheet.
