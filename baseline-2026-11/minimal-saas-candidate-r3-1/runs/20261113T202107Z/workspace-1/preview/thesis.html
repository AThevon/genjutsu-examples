Visual thesis

A cool near-white page with near-black ink, set in the system sans with tabular figures and no web font. The one colour on it is the auditor's red, and it goes only on a value that does not match. The action is solid ink, never red. Matched lines get a quiet grey tick.

The first screen is a real-looking example invoice compared line by line against its purchase order and delivery note. Its values are labelled as an example, and the table takes the full 72rem width.

Interaction thesis

Fast and dry: hover changes colour in 120ms with cubic-bezier(0.2, 0, 0, 1) and nothing moves. Scrolling does nothing. Forbidden: scroll reveals, parallax, bounce, scale on hover, loops, count-ups, glows. The one motion: switching to "What you review" lets the matched lines leave in 160ms, so only the exceptions remain. It runs through the native View Transitions API, and with reduced motion the switch is instant.

Allowed patterns: hairline table rules; tick marks on matched lines; a status colour used only for mismatched values.

Easing - cubic-bezier(0.2, 0, 0, 1), 160ms collapse / 120ms hover
