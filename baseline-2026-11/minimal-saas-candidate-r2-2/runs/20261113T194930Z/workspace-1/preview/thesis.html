Visual thesis

Ploverdesk looks like an auditor's reconciliation worksheet: a cool white ground, near-black ink, ruled with 1px hairlines. Exactly one accent, a burnt-orange exception mark (#A63A12), appears only where a line does not match, never on buttons or decoration. The type is the system sans with tabular figures, set at 400 and 600 only, with a moderate size contrast. There is no web face: the voice comes from the aligned figure columns. Spacing is airy on an 8px base, and every section starts from the same left edge on a 12-column grid, with text held at about 60ch. Components are sharp (2px radius), bordered, flat and unshadowed.

First screen: the headline, one sentence and the trial button sit at reading measure on the left. The width belongs to a worksheet for one invoice, labelled as an illustrative example. Five lines carry a quiet tick, and one line, quantity invoiced against quantity delivered, is circled in the exception colour. At rest it already shows the product's idea, that only that one line needs a person. On a phone the worksheet sits under the CTA. Matched lines shrink to one row each (item and tick), and the exception line keeps its three values (Invoice / PO / Delivery) whole.

Interaction thesis

The motion is fast and dry: 120ms for colour changes on hover, 180ms for fades, all on cubic-bezier(0.2, 0, 0, 1). On hover only colour and underline change, and nothing moves or scales. Nothing happens on scroll. Forbidden: scroll reveals, parallax, bounce or overshoot, scale on hover, loops, count-ups and staggers. The one motion is the worksheet's real toggle, "Show exceptions only". Pressing it fades the matched lines out over 180ms, and the exception line then slides up into place over 240ms (FLIP, transform only). Before it runs, and if it never runs, all six lines are visible and the exception is already circled. With reduced motion, the toggle switches instantly.

Allowed patterns: hairline rules (the worksheet's ruling); tick marks and the circled exception mark (auditor's tick-and-tie); tabular figures in columns.

Assumptions from the brief: product = landing page whose single CTA is /trial, with /demo as a quieter link; audience = finance leads at mid-size EU wholesalers, reading at a desk; mood = quiet, precise, restrained, exact; references = none given, so none borrowed; stack = scanned. No web font is requested, because nobody could approve a third-party font request; the system face stands in, and tabular figures carry the voice.

Set aside: SaaS routine (centred hero, dashboard screenshot in a browser frame, three icon cards, logo strip); its opposite (one huge sentence on a blank page); world 1 (spreadsheet grid); world 2 (bank statement). Kept: the auditor's tick-and-tie reconciliation worksheet.

Easing

cubic-bezier(0.2, 0, 0, 1). Durations: hover 120ms, fade 180ms, settle 240ms. No delay, no stagger.
