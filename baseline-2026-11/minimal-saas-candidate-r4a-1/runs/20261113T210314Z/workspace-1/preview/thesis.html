Visual thesis

A white page with graphite ink. The one image is an auditor's three-way-match worksheet: tabular figures in the system sans, quiet graphite tickmarks on every value that ties, and a single red pencil ring around each value that does not. Red means exactly one thing: this line needs a person.

First screen: left five columns: headline, one sentence, "Start the 14-day trial" (ink button), "or book a demo" (underlined link), terms line. Right seven columns: an example invoice worksheet (labelled as an example) with four lines checked against order and delivery note; one wrong quantity, one wrong unit price and one missing delivery are ringed in red, and one line is matched and ticked. At 375px each line becomes a stacked block with each value beside its document label.

Interaction thesis

Fast and dry: 160ms colour/underline changes on hover with cubic-bezier(0.2, 0, 0, 1). No lift, scale or shadow. Nothing moves on scroll.

The one motion: on first load the worksheet runs its match once. Row by row (300ms start, 90ms stagger), each tied value's tickmark draws in (180ms) and each mismatched value gets its red ring (240ms), about 0.9s in total. Before it runs, the values are on screen without marks. If it never runs, the marks are simply there. With reduced motion, no animation runs and the marks are there from the start.

Allowed patterns: auditor tickmarks and red ring marks on the example worksheet; hairline rules; tabular figures; a once-only, non-looping draw-in of those marks; an example worksheet built as a real HTML table, labelled as an example.

Forbidden: scroll reveals, parallax, bounce or spring overshoot, scale on hover, shadows, gradients, looping animation, counters, logo strips, invented testimonials or metrics.

Set aside: hero + dashboard screenshot + logo strip + three feature cards + pricing tiers; the bare one-line centred page; the accounting ledger; the bank statement. Kept: the auditor's tickmarked worksheet.
