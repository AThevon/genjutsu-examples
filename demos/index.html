genjutsu demos

Each page below is the code a recorded genjutsu run left behind, built as it stands. Nothing was edited after the run, and nothing was added to the pages.

The prompts, transcripts, costs and known defects of every run are in the genjutsu-examples repository and on the examples page.

Examples

  • Nocturnepaint

    A planetarium's late program, scrolling from dusk to the real 22:00 sky over Lisbon.

  • Chef Ovatiobunshin

    A private chef's seven-page site in French and English, built by the run bunshin was extracted from. The client's own deployment, not built here.

  • Atelier Grès, firing stagescast

    A pottery studio's four firing stages, pinned and scrubbed with the scroll.

  • Étalepaint

    A slack-water app's beta page, built from one real day of NOAA tide predictions.

  • Folio, mark as paidcast

    An invoice list whose "Mark as paid" action now feels like the money landed.
