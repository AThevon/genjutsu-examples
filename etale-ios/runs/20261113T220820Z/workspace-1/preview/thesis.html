Étale: Today list → tide detail

This page is the proposal, not the build. It approximates timing and curve only. The real rendering is SwiftUI's own zoom transition, which this HTML doesn't reproduce. The zoom's spring is set by the system, not by the app, so it has no number here.

Interaction thesis (UNVALIDATED, nobody is answering this session): Tapping a slack row in the Today list grows that row into its tide detail with the system zoom navigation transition (.matchedTransitionSource on the row, .navigationTransition(.zoom) on the detail, one shared @Namespace keyed by slack.id). The detail reads as the row opened up, not as a new page sliding in, and swiping down or back collapses it into the same row, interactively. Once the detail is on screen, the day's tide line draws left to right through the slack marker with .smooth(duration: 0.6) after a 0.2 s delay. With Reduce Motion, the system's own handling replaces the zoom and the line is shown already drawn.
